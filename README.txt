BEST FRIEND BIRTHDAY WEBSITE
=============================

1. Open this whole folder in VS Code.
2. In index.html replace [BESTIE NAME].
3. Put 6 photos in images/ named:
   photo1.jpg photo2.jpg photo3.jpg photo4.jpg photo5.jpg photo6.jpg
4. Put your song in music/ named birthday-song.mp3.
5. Replace the sample big letter between the comments in index.html.
6. Gift text is in script.js; search for REPLACE THIS.
7. For easy testing, use VS Code Live Server.
8. To make it public, upload the project to GitHub and enable GitHub Pages.
